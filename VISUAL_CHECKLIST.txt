🛠️ HELPERS TYPESCRIPT DISPONIBLES
═══════════════════════════════════════════════════════════════════════════════

Gradientes:
  • getGradientByLevel(nivel)       → gradient string
  • getGradientByReto(retoTipo)     → gradient string
  
Sombras:
  • getShadow('sm'|'md'|'lg'|'xl')  → shadow string
  
Cartillas:
  • getCartillaLink(slug)           → URL a PDF
  • getCartillaColor(slug)          → color hex
  • getCartillaIcon(slug)           → emoji

Objetos de Estilo:
  • STYLE.cardContainer             → objeto completo
  • STYLE.levelBadge                → objeto completo
  • STYLE.heroSection               → objeto completo
